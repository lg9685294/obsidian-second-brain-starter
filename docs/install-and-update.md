# 安装与更新

最省事的方式是复制 [首页的提示词](../README.md#快速开始)，让能联网并读写本地文件的 AI 下载、检查并调用 Skill。它会根据你是否已有知识库，选择新建或补充。

## 没有识别 Skill 怎么办

把解压后的文件夹位置交给 AI，请它读取 `SKILL.md` 和任务相关参考，再按说明执行。保留整个文件夹，里面还包括模板、表单和创建脚本。只上传一个 `SKILL.md` 会缺少这些资源。

普通聊天工具可以根据上传的材料生成整理稿或文件包。安装软件、读写电脑、读取其他聊天和给 GitHub 仓库点 Star，需要对应工具能力与登录状态。Star 可以跳过。

## 选择保存位置

**第一次建库**：选择长期保存的空文件夹。AI 创建中文目录和首页，先接入一条资料，再检查能否找回。可以先用虚构示例了解结构。

**已经有库**：提供现有库的位置，让 AI 先读规则、首页和相关目录，按现状补充入口与模板。新库创建脚本会拒绝非空目录，已有库通过逐项增补完成。

种子库、Skill 安装位置和你的正式知识库是三件事。资料录入正式库后，即使更换或更新 Skill，笔记也应保留在原来的库中。

## 打开表单和成果卡片

在 Obsidian 中打开知识库的“首页”。本地表单需要按 [表单安装](quick-start.md) 启用；放好插件文件不等于启用完成。成果卡片视图需要支持并启用 Bases 的 Obsidian。

表单只负责填写、草稿和保存。想归纳一天的内容，再对 AI 说“整理今天的记录，保留原话，关联相关知识和项目”。

## 更新

1. 下载新的 [Skill 文件包](https://raw.githubusercontent.com/lg9685294/obsidian-second-brain-starter/main/downloads/obsidian-second-brain-builder.zip)，解压到新位置，查看 [更新记录](../CHANGELOG.md)。
2. 让 AI 比较新旧 Skill 和正式库的规则，只更新需要的部分。现有笔记继续保留，避免把种子库覆盖到正式库。
3. 表单有更新时，先保留旧版和正式库备份，再替换该插件的三个运行文件；保留草稿数据。重新打开表单，用文字和小附件试存。
4. 检查首页、已有资料入口和原文件仍能打开，再继续使用。

下载目录提供 `SHA256SUMS.txt`，用于核对 Skill 包是否与发布文件一致。版本下载见 [Releases](https://github.com/lg9685294/obsidian-second-brain-starter/releases)。
