# 成果整理

成果卡记录用途、版本和文件位置。移动或清理文件时，同步更新笔记中的入口。

## 收录

一份可独立复用的成果建一张卡，记录用途、格式、采用情况、检查情况和原文件位置。不同导出格式放在同一张卡里，说明它们的用途。多件小素材先用总览组织。

原文件放在稳定目录时，知识库可以只保存索引和小预览。临时剪贴板图片需要保存一份可长期访问的原图，多个笔记共享同一个附件。

## 清理

1. 根据实际文件检查内容哈希、依赖和笔记引用。
2. 列出精确候选与保留理由，让用户确认。
3. 要长期留存的文件迁到稳定目录，核对内容后更新链接。
4. 处理确认的副本并记录恢复位置。
5. 再检查成果卡、来源、项目与文件清单。

完全相同的内容出现在两个工程中时，要检查相对路径依赖。压缩包与展开目录逐项比较，保留独有说明和资源。

源文件缺失时，保留成果卡和预览，标明文件情况并记录恢复线索。采用情况、文件可用性和验证结果是三个字段。

仓库提供流程和提示词。实际移动与删除由你授权的助手或人工执行。
