# 用 AI 开始使用 Obsidian

把仓库链接交给能操作电脑、读写本地文件的 AI，再按下面两步发送指令。

## 1. 让 AI 安装

复制给 AI：

```text
请从官网安装 Obsidian，
将这个仓库中的 starter-vault
作为独立知识库打开，
保留已有笔记和设置。
```

按提示授权后，让 AI 告诉你知识库保存在哪个文件夹，并打开首页。

## 2. 让 AI 记笔记

安装完成后，在同一对话复制这句：

```text
请读取知识库的 AGENTS.md，
记录我接下来发的内容，
保存为笔记，并告诉我去哪里查看。
```

再把要记录的文字、图片或文件发给 AI。它按库内规则整理保存，并返回笔记入口。

## 日常使用

之后直接告诉 AI 要做什么，例如：

- 整理今天的会议，列出结论和待办。
- 找我收藏过的会员卡设计参考，附上原文件。
- 我想回顾品牌设计，帮我找相关笔记或课程时间。

<summary>手动安装与使用（备用）</summary>

### 安装

从 [Obsidian 官网](https://obsidian.md/download) 下载对应电脑系统的版本，完成安装。基础使用免费，无需注册账号；Sync 和 Publish 是可选的付费服务。[费用说明](https://obsidian.md/pricing)

回到 [仓库首页](../)，在文件列表上方点击 `Code → Download ZIP`，解压后放到长期保存的位置，例如“文稿 → 个人知识库”。[GitHub 下载说明](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)

### 打开知识库

在 Obsidian 的库管理界面选择“打开本地仓库 / Open folder as vault”，选中解压后的 `starter-vault` 文件夹。[建库说明](https://obsidian.md/help/vault)

```text
项目文件夹
├─ docs             说明文档
├─ plugins          表单源码
└─ starter-vault    选择这个文件夹
   ├─ 首页.md
   ├─ +（收集箱）
   ├─ Atlas（知识地图）
   ├─ Calendar（日历记录）
   ├─ Efforts（项目行动）
   ├─ x（系统支持）
   └─ .obsidian     设置与本地插件
```

打开左侧的“首页”，可以看到记一笔、找知识、看项目和找成果四个入口。

“库”就是装笔记的文件夹，`.md` 是笔记使用的 Markdown 文本格式，`.obsidian` 保存配置与插件，在文件管理器中可能隐藏。移动或备份时保留整个库文件夹。文字内容也可以用其他文本编辑器读取。[笔记格式说明](https://obsidian.md/help/create-note)

已有个人知识库时，先独立打开示例库，试用后再选择需要的目录与模板。合入前备份原库，并保留原有配置。想从空白开始，可以在库管理界面选择“创建新库”。

### 写笔记

在“+（收集箱）”上右键，选择“新建笔记”，命名为“会员卡标题”。输入下面的文字，再改成自己的记录。

```markdown
# 会员卡标题

先确定会员名称和等级数字的主次，再比较材质效果。
下次修改标题时，参考这条记录。

关联项目：[[示例会员卡项目]]
```

输入 `[[` 后，可以从候选中选择已有笔记。编辑时按住 Mac 的 `Command`，或 Windows、Linux 的 `Ctrl` 再点击链接，就能打开关联笔记。[链接说明](https://obsidian.md/help/link-notes)

参考图可以直接拖入笔记，再写一句收藏理由。拖入的文件会复制到库内的附件位置；大型录屏和工程可以先记录原文件的稳定位置。[附件说明](https://obsidian.md/help/attachments)

### 查找笔记

| 查找方式 | 操作 |
| --- | --- |
| 按名称 | Mac 按 `Command + O`，Windows、Linux 按 `Ctrl + O`，输入“会员卡标题” |
| 按内容 | 打开左侧“搜索”，输入“等级数字”等正文关键词 |
| 按项目 | 在项目中添加相关笔记链接，以后从项目进入 |

快速切换器按笔记名或别名查找；正文内容使用 [全库搜索](https://obsidian.md/help/plugins/search)。快捷键说明见 [快速切换器](https://obsidian.md/help/plugins/quick-switcher)。

打开“示例会员卡项目”，添加 `[[会员卡标题]]`。以后就可以从这个项目返回刚才的记录。项目与笔记之间的关联需要手动或由获得授权的助手补充。

### 录入表单

会议或课堂中可以使用本项目的表单，按提示填写讨论、结论和待办，并添加图片或文件。表单支持会议、课堂、网页、灵感和项目五种类型，每种类型保留独立草稿。

示例库已经附上运行文件。按照 [表单安装](quick-start.md) 启用插件后，按 Mac 的 `Command + P`，或 Windows、Linux 的 `Ctrl + P` 打开命令面板，搜索“新建笔记表单”。[命令面板说明](https://obsidian.md/help/plugins/command-palette)

表单目前仅支持桌面，尚未上架社区插件目录。使用普通笔记可以保持受限模式；启用本地表单需要信任其代码并允许第三方插件运行。[插件说明](https://obsidian.md/help/plugin-security)

### 日常整理

日期记录保存当时发生的事，主题笔记保存可复用的方法，项目笔记保存当前决定和下一步。记录结束后，再把它们关联起来。

让助手整理时，可以直接说明范围和要求。

> 整理今天的会议记录，保留原话，区分已确认决定与建议。把相关方法连到主题，项目进展连到项目，列出更新的笔记。跳过示例内容。

能够访问本地文件的助手需要获得相应授权。普通聊天工具可以读取上传的笔记，生成整理稿后再保存回库。相关规则与示例见 [协作流程](ai-workflow.md)。

### 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 打开后全是代码和说明 | 重新选择项目内的 `starter-vault` 文件夹 |
| 首页没有填写按钮 | 按照表单安装说明启用本地插件 |
| 成果墙没有显示卡片 | 使用支持 [Bases](https://obsidian.md/help/bases) 的版本，并在核心插件中启用 Bases |
| 想在手机上使用 | 普通笔记可使用 [移动版](https://obsidian.md/help/mobile)，表单目前仅支持桌面；跨设备资料需要另行同步 |

更多模块见 [个人知识库说明](../README.md)。
