# 模块说明

表单负责录入，助手处理检索与整理，用户确认目标、采用版本和删除范围。各模块的输入与保存内容如下。

| 模块 | 你提供什么 | 工具或助手处理什么 | 保存什么 |
| --- | --- | --- | --- |
| 场景表单 | 原话、截图、附件 | 表单给出填写提示，保存草稿和正式笔记 | Calendar中的原始记录 |
| 日期归纳 | 要整理的日期与范围 | 助手按主题去重、保留出处、识别决定 | 日期回顾与知识链接 |
| 需求检索 | 当前想解决的问题 | 先查主题入口，再读来源 | 带理由和出处的回答 |
| 课程索引 | 录屏或已有转写 | 转写工具处理音频，助手归纳并抽样核对 | 摘要、时间码、核对状态 |
| 成果管理 | 原文件、用途、版本 | 检查文件位置，建预览和成果卡 | 源文件入口与采用情况 |
| 清理同步 | 精确的文件范围 | 助手列候选，核对依赖与链接 | 清理方案与后续状态 |
| 对话接力 | 当前任务及可读历史 | 汇总目标、决定、证据和下一步 | 可带到新对话的交接稿 |

## 数据关联

Calendar保存当时发生的事，Atlas保存可复用知识与来源，Efforts保存当前行动和交付。来源笔记与知识卡互相链接，成果卡再连接项目和实际文件。

图片可以直接存在附件中。大工程和录屏适合保留在稳定目录，用项目笔记记录打开方式与需要的软件。路径移动后同步更新来源、成果卡和相关项目。

## 分工

你决定目标、采用版、业务取舍与删除范围。助手承担检索、归纳、关联、文件检查和可恢复更新。表单只负责录入，转写和跨聊天读取依赖另行配置的工具。

当来源互相矛盾时，保存两种说法与日期，优先核对最近确认的用户决定。无法取得原文的资料，标注读取范围和缺口。
