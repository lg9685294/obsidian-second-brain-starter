# 个人知识库的搭建方法

这份 Skill 总结了我们实际搭建第二大脑时做过的选择：怎样让目录看得懂、录入不面对空白页、资料有出处、课程能定位、成果能找回，以及新聊天怎样继续工作。

最终交付是一套放在本地、可由 Obsidian 打开的文件，以及 AI 继续整理和检索时要读取的规则。

## 从实际需求开始

最初的习惯是“每天按日期和信息类别总结”。这能保留过程，但下一次做设计时，往往想问“会员卡可以参考什么”，不一定记得资料是哪天收的。

因此保留三种互相连接的视角：**日期看经历，主题找方法，项目推事情**。资料和成果再连到这三种入口。目录参考 [ACE](https://blog.linkingyourthinking.com/notes/ace-folder-framework)，每层附中文用途说明。

| 入口 | 放什么 | 适合回答什么 |
| --- | --- | --- |
| Calendar（日历记录） | 会议原稿、每日记录与回顾 | 昨天讨论了什么？ |
| Atlas（知识地图） | 主题、方法、来源与成果卡 | 现在做这个可以参考什么？ |
| Efforts（项目行动） | 目标、已确认决定与下一步 | 这个项目做到哪了？ |

收集箱放尚未整理的内容，系统支持目录存模板、附件和规则。已有库优先保留原结构，补充入口与关联。

## 首页和录入界面

首页保留四个日常入口：**记一笔、找知识、看项目、找成果**。详细目录继续存在，但开始操作时不用先理解整套分类。

录入表单按会议、课堂、网页、灵感、项目分场景。会议可以依次填写“讨论了什么、确认了什么、下一步谁做”，图片和附件有单独入口。它保存草稿和 Markdown 原稿；归纳与关联在用户发出指令后进行。

## AI 怎样接着处理

在库内放 `AGENTS.md` 和协作规则，写清目录入口、日期时区、来源保留、更新方式与示例识别。新助手先读这些，再按当前问题读取相关笔记。

用户原话、AI 建议、用户决定、实际验证分别保存。一次“整理今天”先查已有内容，补充日期回顾，再把可复用内容连到主题，把当前行动连到项目。读取范围不足时写明缺口。

网页保存收藏理由和适用任务；课程索引保留原视频与时间；成果卡连接预览和原文件。这样“我要做会员卡标题”可以同时找到方法、参考、课程与素材。

## 资料怎样接入

| 资料 | 建立哪些记录 | 需要检查什么 |
| --- | --- | --- |
| 网页和图片 | 原出处、要点、收藏理由、适用任务 | 实际读到了什么，哪些是自己的判断 |
| 课程录屏 | 原片、转写、主题、相对原片的时间码 | 先测小样本，核对专有词和关键画面 |
| 多个聊天 | 正文来源、日期、决定、任务交接 | 是否真的取得这些聊天的正文 |
| 设计和工程文件 | 成果卡、封面、版本、采用情况、原位置 | 文件能否打开，依赖和引用是否完整 |

视频和大型工程优先留在稳定原位，库内保存索引与轻量预览。临时附件保存一份持久副本，多处引用。移动文件后更新入口，删除前检查具体文件及其依赖。

## Skill 里有什么

```text
obsidian-second-brain-builder/
├── SKILL.md                   AI 执行搭建的入口
├── references/                结构、资料接入与验收方法
├── scripts/bootstrap_vault.py 新库预览与创建脚本
├── assets/starter-vault/      中文目录、首页、规则和模板
├── assets/form-plugin/        可选表单的源码与运行文件
└── agents/openai.yaml         支持该格式工具的显示信息
```

新库创建脚本默认只显示计划，明确执行后才写文件；目标目录已有内容时会停止。已有库通过 AI 按现状增补，避免覆盖。表单文件可以随新库放好，启用与实际保存需要另行完成和验证。

`SKILL.md`、参考文件和模板可由不同 AI 阅读。能否识别 Skill、直接写入本地文件或操作软件，取决于使用的工具。文件包遵循说明与资源分开的结构，可参考 [OpenAI 的 Skill 文档](https://developers.openai.com/plugins/build/skills)。

## 怎么确认搭好了

拿一条资料走完“录入、归纳、按问题检索、打开来源”。再换一个说法提问，检查能否找到正确入口。课程需要真实原片才能验证分钟，成果需要检查源文件；只有示例时明确标为演示。

交付时给出首页位置、已建模块、检查结果和待配置事项。有关课程转写、跨聊天访问、插件原生运行的完成状态逐项记录，避免只复制目录就宣称所有功能完成。
