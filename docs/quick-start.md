# 表单安装

本项目表单用于在桌面 Obsidian 中填写笔记、添加附件和保存草稿。首次使用 Obsidian，可以先阅读 [Obsidian 入门](obsidian-quickstart.md)。

## 打开示例库

下载并解压仓库。在桌面 Obsidian 中选择“打开本地仓库”，选择 `starter-vault`，再打开“首页”。仓库有完整演示记录，可以先跟着链接阅读。

首页的“记一笔”打开填写说明，“找知识”按任务选资料，“看项目”展示当前决定，“找成果”展示封面和文件入口。Bases 是 Obsidian 的核心插件，支持按属性筛选与卡片封面。使用成果墙前，在设置的核心插件里确认已开启 Bases。[Obsidian 官方说明](https://help.obsidian.md/bases)

## 启用插件

示例库中已放入 `.obsidian/plugins/second-brain-capture/` 的三个运行文件。先阅读 `plugins/second-brain-capture/README.md` 和源码，再在该示例库的第三方插件设置中允许并开启“记一笔 · 新笔记表单”。首次运行建议就在示例库试填。

通过命令面板搜索“新建笔记表单”，或左侧笔记图标打开。Mac 默认快捷键为 Control + Command + N，其他桌面系统为 Ctrl + Alt + N。有冲突时使用命令面板或自行改快捷键。

选一种场景，写一句内容或添加一个附件，再点“保存到知识库”。每种场景有一份草稿，看到“草稿已保留”后可关闭。单文件上限为200 MiB，大录屏在正文记录稳定位置。默认时间来自设备时区，生成的笔记会记录所用时区。

## 整理记录

让助手读取本地库的 AGENTS.md 与协作规则，再使用 `prompts` 中对应的提示词。首次可尝试“查找示例项目中与会员标题有关的参考，给我笔记和出处”。

只整理你指定的笔记范围。助手返回改了什么、来源在哪里、哪些结论仍待确认。纯聊天工具可以读取你上传的相关笔记，生成整理稿，由你保存回库。

## 放进自己的库

先保留现有库备份。将需要的中文目录和模板逐项合入，处理同名笔记后，再选择是否复制本地插件。插件使用本项目约定的 Calendar、Efforts 和 x 目录。

日期目录、知识入口与项目入口建立链接。每次导入先查同题笔记和已有文件，原始记录继续保留。
