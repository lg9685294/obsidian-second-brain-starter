# 验证记录

表单和资料整理流程已在一套个人知识库中使用。以下分别记录原环境中的使用情况、公开版检查和尚未验证的范围。

## 原环境使用

- 桌面Obsidian中打开表单、保存普通Markdown、导入附件与重启后继续读取。
- 成果卡片墙、中文属性和日期筛选。
- 课程摘要、自动全文、字幕及原视频路径的关联。
- 对话归纳、原话保留、跨聊天来源范围说明。

这些流程来自一套个人知识库的实际使用。公开版使用新编写的匿名示例，不附个人对话、课程原片或第三方参考图。

## 公开版检查

自动检查结果见 [public-checks.json](../validation/public-checks.json)，浏览器检查见 [browser-checks.json](../validation/browser-checks.json)。本地源码测试覆盖附件和仅附件保存、路径检查、时区、重复保存、保存失败及中断后恢复。页面检查覆盖说明页和表单的桌面与窄屏预览。

入门指南的检查见 [guide-checks.json](../validation/guide-checks.json)，包括主说明开头的引用、两篇之间的跳转、章节定位、桌面与窄屏排版。教程操作依据文中的官方帮助，本轮未重新安装 Obsidian。

运行中的表单适配了公开ID与设备时区。其完整源码与打包文件一起提供。单一桌面环境的使用记录及浏览器预览覆盖有限，Windows、Linux与手机端的原生使用另需测试。当前插件标记为桌面专用。

## 搭建 Skill

`obsidian-second-brain-builder` 已通过 Skill 格式检查。独立解压下载包后，验证了新库创建、仅预览不写入、首页链接、示例成果与 SVG 来源链，以及已有库内容保持不变。选配表单时只放置运行文件，没有启用插件或修改受限模式。结果见 [skill-builder.json](../validation/skill-builder.json)。

这些检查验证了文件包和创建脚本，没有做另一个 AI 的独立执行测试，也没有重新测试原生 Obsidian 安装或真实课程的时间码。分享页的桌面和窄屏预览、复制指令及跳转另记在 [skill-sharing.json](../validation/skill-sharing.json)。

GitHub 版采用 README、相对链接、图片、表格和代码块组织内容。仓库文件列表、README 定位、指令复制、窄屏显示和 Skill 原文视图已检查，结果见 [github-builder.json](../validation/github-builder.json)。这份报告记录发布前的本地模拟检查，不代表公开页面检查。

快速开始已合并为一段包含下载、安装、调用和 Star 的提示词。上述浏览器检查只验证复制与显示，没有执行下载、安装或 Star。公开地址及下载包在发布后另行核对；Star 是使用者可跳过的操作。

## 使用限制

自动转写可能识别错专有名词和参数，重要引用应回看原视频。语义检索需要助手实际读取知识库。跨聊天只总结可取得的正文，缺失的来源在回顾中说明。附件选择后复制到库内，移除草稿关联时已经复制的文件仍可能存在，清理时按引用检查。

表单没有内置AI接口。外部助手、模型、同步或转写服务的用量按你实际使用的服务计算。草稿与同步各有作用，完整恢复仍依赖原文件及备份。
