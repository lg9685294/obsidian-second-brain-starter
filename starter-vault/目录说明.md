# 每层目录的用途

用途为不用记住英文缩写，也能看懂文件放在哪里。

- **+（收集箱）** 先放暂时没想好归属的内容与录入入口。
- **Atlas（知识地图）** 保存主题、知识、来源与成果卡片。
- **Atlas（知识地图）/Maps（主题导航）** 从需求找到相关知识与来源。
- **Atlas（知识地图）/Dots（知识卡片）** 保存可复用的理解及其适用范围。
- **Atlas（知识地图）/Sources（参考来源）** 保存原始出处、参考拆解与核对范围。
- **Atlas（知识地图）/Assets（成果卡片）** 连接用途、预览、版本与实际文件。
- **Calendar（日历记录）** 按时间保留原话、日记与回顾。
- **Calendar（日历记录）/Notes（每日记录）** 保留当天的原始记录。
- **Calendar（日历记录）/Notes（每日记录）/表单记录** 本地表单的正式保存位置。
- **Calendar（日历记录）/Reviews（回顾总结）** 保存按日期或阶段归纳的回顾。
- **Efforts（项目行动）** 连接当前目标、成果和下一步。
- **Efforts（项目行动）/On（正在推进）** 记录当前正在做的项目。
- **x（系统支持）** 保存附件、模板、规则与维护记录。
- **x（系统支持）/Rules（协作规则）** 说明助手如何检索、整理和更新。
- **x（系统支持）/Templates（笔记模板）** 提供可以按需取用的记录结构。
- **x（系统支持）/Attachments（图片与素材）** 保存能长期访问的附件和示例图。
- **x（系统支持）/Attachments（图片与素材）/表单附件** 保存表单导入的图片和文件。
- **x（系统支持）/Logs（维护记录）** 保留整理、迁移与核对的记录。

每层都有“本层说明”。日常从[[首页]]开始。
